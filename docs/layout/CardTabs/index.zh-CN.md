## 组件说明

与 [Ant Design](https://ant.design) 的 [Tabs](https://ant.design/components/tabs) 组件类似，但 `CardTabs` 采用了卡片样式和边框。

## 导入组件

```jsx | pure
import {CardTabs} from '@yookue/ant-buddy-pro';
```
